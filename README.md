**Lantern Twins: Spot the Difference** — an original spot-the-difference game drawn entirely in code on a 1280×720 canvas. Five hand-painted-in-code scenes (Harbor at Dusk, Night Market, Botanical Garden, Mountain Cabin, Clockmaker's Workshop) with 5–13 fair differences each: recolours, removals, additions, flips, count and number changes hidden inside rich scenes. Click either panel to mark a find (ring appears on both panels), build combos, spend one of three hints for a quadrant glow, beat the timer, earn up to three stars per level. Full keyboard play, generated WebAudio sounds, no libraries, no assets, no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
